# Flashcard App

My first project in TripleTen's AI-Assisted Software
Engineering program. It includes decks of flashcards,
each of which can be viewed in a carousel.

## Features

- Dynamic Deck Navigation: Browse custom study decks with real-time progress indicators and card counts.

- Interactive Flashcard Carousel: Seamlessly navigate between cards with built-in boundary checks (disabling navigation buttons at the start or end of a deck).

- Card Flipping Mechanism: Instantly toggle between questions and answers.

## Technologies

- HTML: Semantic markup utilizing HTML templates (<template>) for efficient DOM cloning and rendering.

- CSS: Modular styling structured using the Block Element Modifier (BEM) methodology and custom color modifiers.

- JavaScript: DOM manipulation, and hash-based routing.
